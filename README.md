# Deep Learning in Skin Lesion Segmentation: A Literature Review

This repository contains the seminar presentation, review notes, and literature comparison matrix compiled as part of my Master's studies in Computer Engineering. 

## 🔍 Focus Areas
- Comprehensive review of deep learning architectures (CNNs, U-Net variants, Transformers) applied to skin lesion segmentation.
- Comparison of evaluation metrics (IoU, Dice coefficient, sensitivity, specificity) across recent studies.
- Analysis of current challenges, data preprocessing techniques, and future directions in medical image analysis.
